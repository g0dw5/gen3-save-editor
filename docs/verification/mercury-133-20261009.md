# Mercury FC 1.33 adaptation / 水银 FC 1.33 适配验证

Date: 2026-10-09. Editor development version: **0.3.1**.
Exact ROM MD5: `5ffb1cbd5c28cda9b987b3b445da68e0` (32 MiB),
SHA-256: `9801866280284a8ac12650666b8526ff3d07aa455f8dc623c2c56c0537313ec4`.
Source ROM and user SAV files stayed unchanged. Private ROMs, saves, emulator
states, vectors and screenshots are in ignored local analysis, outside release inputs.

## Change boundary / 改动边界

FC 1.33 relocates content tables and native routines; replacing the fingerprint
alone is insufficient. One current Mercury profile replaces FC 1.2. Both removed
1.1 and 1.2 inputs are rejected by real-file regression. No dual-version engine
branches, built-in extracted catalogs, ROM writes or derived-ROM exports were added.
The other four exact ROM profiles and native rules are unchanged.

水银只保留 FC 1.33，未为 1.2 增加兼容分支。数据来源仍为当前 ROM；更新的是指纹、
地址与验证输入。当前地址见[1.33 地址文档](../research/mercury-fc-133.md)。
老版本验证文档保留其历史版本含义，不能作为本版本已验证的替代证据。

## SAV safety and real save/reboot / 存档安全及游戏内保存

A disposable native battery fixture was edited through the public save workflow:
IV/EV/markings in box 25, an occupied swap across boxes 20/23, an empty-slot move
from box 1 to box 25, and batch friendship edits. The game booted normally,
loaded the edits, saved using ordinary key input and continued after a fresh boot.
No cheats, savestate loading, RAM writes or replaced routines were used in this
save-roundtrip run.

- Every native compact-box pointer and physical region matched the exported SAV.
- Party and all **808 inventory slots** matched native RAM and re-read snapshots.
- Individual and bag snapshots remained equal after native save/reboot; the
  native save counter advanced from 4 to 5 and the export was not overwritten.
- Three intentionally wrong party/storage/bag expectations were rejected.
- Synthetic cross-ROM tests cover transaction failures, backups, undo, external
  changes, exact individual preservation, all box slots and multi-field edits.

测试用旧版电池存档可在 1.33 中载入并正常保存。未覆盖所有旧剧情状态的版本迁移；
没有改写用户的实际存档，也没有自动迁移剧情标记。

## Ten common cheats / 十项通用金手指

Fresh 1.33 overworld/battle states were produced from a normal battery boot; old
1.2 emulator states were not reused. Wild-battle setup for the battle fixture
invokes the current ROM's native setup. Code decoder tests additionally assert
allowed changed spans, exact source bytes and eight enable/disable restore cycles.

- Walking encounters: native tile checks plus **384** booted-map cases, with
  encounters present when disabled and suppressed when enabled.
- Catch: **90** native throw cases, including trainer/Safari rejection controls.
- Hatching: **360** boundary, egg/bad-egg and party permutation cases.
- Daycare: **640** cases preserving incompatible, empty, pending and early gates.
- Species/level/shiny: **768** wild-slot cases, **32** non-wild exact-preservation
  controls, and **256** lead-ability cases. Wild-only caller guards are relocated.
- Teleport: **686** eligible map records and five native setter/transition cases;
  this does not prove all target maps are currently reachable.
- Portable PC: real frame-loop open/exit, deposit/withdraw, slot moves, normal
  save/reset/reload and three reopen/cancel cycles; registered item retained.
- Recovery and Protect: fresh 1.33 battle checks and all other four exact-ROM
  controls pass; opponent state retained, recovery hook restored when disabled.

Old FC 1.2 codes are not interchangeable with FC 1.33 codes. Generate from the
loaded exact ROM. Emulator support and facility exceptions remain as described
in the player cheat guide.

## Cross-ROM and UI / 跨 ROM 与界面

Fresh reader regressions pass for Dark Phantom BW/DP, Spanish Rocket and Ultimate
Emerald. Five-ROM acquisition queries pass for Pokémon, items, moves and native
resource links, including read-only SAV overlays. The five-ROM player-reference
and adventure test checks runtime names, evolution links, item visibility,
map navigation and that the public query flow does not mutate a SAV.

Rust formatting, strict Clippy across core/CLI targets and TypeScript/Prettier
checks pass. Browser and frontend-build outcomes are recorded after final execution
below; do not infer them from a passing backend API.

## Reproduction / 复现

Use `GEN3_ROM_MERCURY133` / `GEN3_SAVE_MERCURY133` for current inputs, plus
`GEN3_ROM_BW`, `GEN3_ROM_DP`, `GEN3_ROM_ROCKET` and `GEN3_ROM_ULTIMATE`.
The removed-input tests alone use `GEN3_ROM_MERCURY11` / `GEN3_ROM_MERCURY12`.
Native input vectors are generated afresh; never reuse an old version's states.
