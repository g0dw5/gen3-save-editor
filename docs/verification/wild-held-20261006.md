# Native wild held items / 原生野生携带道具

Read-only increment after `f579d9b`; version unchanged. This verifies ordinary
single-wild assignment, not complete encounter/access/facility behavior.

## Rules and scope / 规则与范围

| Exact profile | Native routine | Tested leading ability modifiers | Exceptional layout |
|---|---|---|---|
| Dark Phantom BW | `0x0806EA68` | 14 | 420 |
| Dark Phantom DP | `0x0806EA68` | 14 | 420 |
| Spanish Rocket | `0x0809C610` | 14, 105 | 420 |
| Ultimate Emerald | `0x0806EA68` | 14, 28, 105 | 420 |
| Mercury 1.2 | `0x080443F4` | No leading-ability branch in this routine | None |

Names, item columns, exceptional species/item tables and RNG parameters are read
from the current ROM. The complete native routine executes in isolated RAM;
there are no function hooks, official-percentage fallbacks or ROM writes. The
baseline uses a minimal synthetic non-modifying lead and is labeled a simulated
condition. A loaded SAV supplies the complete first party record without edits.
In qualified modifier branches eggs disable the modifier; fainted HP does not.
Ability slot variants are checked through native getters, including Ultimate's
hidden slot. This does not assert general field-ability behavior elsewhere.

The current routines consume one native 16-bit RNG output modulo 100. Counts
assume uniform outputs: residues 0–35 have 656 preimages and the rest 655. Native
thresholds and item selection execute, rather than being copied into a percentage
catalog. A rare-item outcome can therefore be 3,275/65,536 (approximately 5.00%)
or 13,100/65,536 (approximately 19.99%) in the tested contexts. These are conditional
assignment probabilities, not encounter probabilities or predictions of the next
encounter. Common/rare equality and exceptional branches are also executed.
Ultimate's exceptional-layout fallback uses a legacy rare-column pointer distinct
from its ordinary current species table; runtime candidate indexing includes it.

## Query workflow / 查询流程

Item sources join actual grass/cave/surf/dive/rock-smash/rod encounter references.
They retain map, levels, slot weight, selector/time conditions and related species.
Different time tables are not combined or described as distinct grass patches.
Unreferenced held columns remain an explicit unknown/unplaced source. Zero item
IDs are not listed as obtainable objects. Native failure retains technical evidence
and unknown chance. Static map references do not establish current access.

The shared bilingual display supports item → Pokémon → back, item → map/entry →
back, collection suggestions and escaped standalone HTML. Current-party and baseline
chances appear separately from encounter slot probability. The cache is tied to
ROM identity, normalized layout and the full raw leading record.

## Independent evidence / 独立证据

`scripts/verify_wild_items.py` verifies all five exact fingerprints and executes
native routines with Unicorn using synthetic RAM only. It opens no user SAV,
patches no ROM and bypasses no native getter/setter/selection routine.

- 327,680 native RNG outputs: all 65,536 outputs per fingerprint, checking inverse seeds.
- 1,090 distribution contexts: 260 each for BW, DP, Rocket and Ultimate; 50 for Mercury.
- 327,000 assignment cases: 100 residues × three distinct high-output preimages
  per context, checking identical selected items, one RNG consumption and unchanged lead bytes.
- Contexts cover item-column patterns, exceptional table species/layouts, available
  modifier ability slots, eggs and fainted leads. Rust sandbox distributions match
  all 1,090 independent contexts and preserve source ROM and raw party data.
- Public fixtures check actual random method references, slot/time preservation,
  unreferenced uncertainty and no empty-item source. Real five-ROM acquisition
  queries check map/method/chance association and read-only SAV context.
- `scripts/test_wild_held_ui.py` checks bilingual chance labels, item/species/map/back,
  collection HTML escaping, a compact window and absence of save-mutation requests.

Private ROM paths, probe JSON and logs remain outside tracked source/release inputs.
To reproduce with the existing five `GEN3_ROM_*` variables:

```sh
uv run --with unicorn python scripts/verify_wild_items.py > /private/wild-items.json
GEN3_WILD_ITEM_PROBES=/private/wild-items.json cargo test -p gen3-core local_native_wild_item_distribution_parity -- --ignored --nocapture
cargo test -p gen3-core
cargo test -p gen3-core local_query_ -- --ignored --nocapture
uv run --with playwright python scripts/test_wild_held_ui.py
```
