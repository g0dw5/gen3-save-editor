# 金手指 / Cheat codes

先打开对应 ROM，再从顶栏打开“金手指”。无需 SAV。选择功能后复制**完整代码组**，
在模拟器里按页面指定的格式添加；程序不会替你启用代码，也不会改写 ROM 文件。

Open the matching ROM, then **Cheats** in the toolbar. No SAV is needed.
Copy the **complete code group** and add it using the indicated format in your
emulator. The editor does not enable codes or write ROM files.

## 五个 ROM 的通用功能 / Common features in all five ROMs

漆黑的魅影 BW／DP、西班牙火箭队、究极绿宝石及水银 1.33 均提供以下 10 项。
相同功能的代码可能不同，必须使用当前 ROM 生成的代码。

Dark Phantom BW/DP, Spanish Rocket, Ultimate Emerald and Mercury 1.33 all provide
these ten features. Codes can differ between ROMs; use those generated for your
currently opened ROM.

|---|---|
| 暂停走路遇敌 / Pause walking encounters | 暂停行走触发的随机战斗，钓鱼、定点和剧情战不受影响。 / Walking-triggered random battles only. |
| 野生投球必定捕获 / Guaranteed wild capture | 仍消耗球，保留实际球种及本作捕捉限制。 / Consumes the actual ball; retains native capture restrictions. |
| 加快孵蛋 / Faster hatching | 取消普通同行蛋的等待门槛，仍需行走。 / Removes the ordinary party-egg waiting gate; keep walking. |
| 兼容组合必定产蛋 / Compatible daycare eggs | 正常产蛋检查时生效；不兼容组合仍不产蛋。 / At the normal check; incompatible parents still produce no egg. |
| 随身电脑 / Portable PC | 在可自由行动的地图按 SELECT 打开电脑。 / Press SELECT in an eligible overworld location. |
| 指定遇怪与等级 / Species and level | 选择普通野生宝可梦与等级，随后触发随机相遇。 / Choose a species/level, then trigger an ordinary wild encounter. |

Ultimate Emerald also has two exclusive recipes: disable AI reading the current
turn's input, and correct the direction of difficulty accuracy bonuses.

## 使用前须知 / Before use

- 先在战斗外正常保存并备份。普通 GameShark 条目按页面说明重启生效；停用时
  关闭整组并重启。不要把即时存档当作原始备份。
- **紧急恢复、持续守住和传送**按各自说明即时启停；不要为救急重启正在打的战斗。
  恢复后立即停用；已经进入败北结算时无效。联机、伙伴战及部分特殊战斗不适用。
- 持续守住使用 **CodeBreaker**；其余使用 **GameShark Advance V1/V2**。
  去掉空格只改变排版，不会转换成其他协议。
- 传送列表提供入口线索，不保证剧情已解锁；不要传到未知、剧情专用或无法返回的地点。
- 已用本地 mGBA 验证所述范围；手机模拟器、全部设施与长期同时启用多组代码未逐一验证。

- Save normally outside battle and keep a backup. Follow each ordinary GameShark
  entry's restart instructions; disable the whole group and restart to stop.
- **Recovery, Protect and teleport** use their own live enable/disable steps.
  Do not restart an active battle for rescue. Disable recovery immediately after
  use; it cannot reverse an already-running whiteout. Special/link/partner battles
  have restrictions.
- Protect uses **CodeBreaker**; other recipes use **GameShark Advance V1/V2**.
  Removing spaces changes layout, not protocol.
- Teleport entrances do not prove story access or a safe return route.
- The stated scope was tested locally in mGBA. Mobile emulators, every facility
  and prolonged combinations of multiple codes were not individually tested.

支持的精确 ROM 指纹见首屏及 README。水银 1.1／1.2 不支持。
Supported exact ROM fingerprints appear on the welcome screen and in README.
Mercury 1.1 is unsupported.
