# 三代改版修改器 · Gen III ROM Hack Editor

下载：[GitHub Releases](https://github.com/g0dw5/gen3-save-editor/releases/latest)。选择 Windows 64 位或 Apple Silicon Mac 安装包；附件包含程序与说明，不包含 ROM 或存档。

[English](README.md)

面向用户自备三代改版 ROM 的本地桌面修改器。Rust 负责解析和事务读写，React
提供中英双语界面，Tauri 提供跨平台桌面外壳。名称、图片和地图由 ROM 实时读取。

**当前为开发预览。** 漆黑的魅影 BW / DP、西班牙火箭队 2.1 汉化版和究极绿宝石 5.5 共用编辑界面。测试与尚未完成的项目见
[验证记录](docs/IMPLEMENTATION.md)，不会把尚未验证的能力写成完整支持。
水银 FC 1.2 的 ROM 资料和存档编辑已在开发分支接入；扩展图鉴位和金手指仍在研究。

## 金手指

先打开完整指纹匹配的 ROM，再从顶栏打开“金手指”，无需存档。金手指窗口沿用
当前打开的 ROM。一个已验证条目是**究极绿宝石 5.5 全模式关闭 AI 窥屏**，
严格匹配 MD5 `17ce9785b33319b3dbda9a5d37c57ec1`。
究极绿宝石现已接入 ROM 资料和存档修改；具体差异与验证边界见
[适配说明](docs/research/ultimate-emerald-55.md)。
四个版本均支持随身电脑、暂停走路遇敌、野生投球必定捕获、加快同行蛋
孵化、指定遇怪／等级、普通野生必闪，以及带区域→地图二级选择、编码和入口格位
的传送；名称和地图条目均实时读取 ROM。西班牙火箭队另有兼容寄养组合必定产蛋。
按精确指纹分别开放，新增条目均有
mGBA 原生函数回归测试，手机模拟器尚未实测。
四款 ROM 都有战斗紧急整队恢复：己方指令界面按 L＋R＋SELECT，立即治疗、复活，
不占吃药回合。需完整启用与当前 ROM 匹配的整组代码，并使用能即时启停补丁的模拟器。
四款 ROM 还支持 CodeBreaker「己方持续守住」，用游戏原生守住判定拦截可守住的招式；
每款只需四行，其他战斗标记不会被覆盖。
详见[使用方式、格式、范围与开发测试](docs/cheats.md)。

## 支持版本

| ROM | 必须匹配的 MD5 | 字节数 |
| --- | --- | ---: |
| 漆黑的魅影 5.0EX+BW | `0d9b129f7dd76895f79bb47ad7dec2fe` | 33,554,188 |
| 漆黑的魅影 5.0EX+DP | `cb2940215f4dafb1bef133c3af379f44` | 33,554,188 |
| 西班牙火箭队 2.1 汉化版 | `59c658a1081f542086de1060bb65f0b3` | 33,554,432 |
| 究极绿宝石 5.5 · 失落之古遗 | `17ce9785b33319b3dbda9a5d37c57ec1` | 33,554,432 |
| 宝可梦水银 FC 1.2（开发分支） | `f323df1792ac68462a34b42fe8571533` | 33,554,432 |

存档需为 128 KiB 的 `.sav` / `.srm` 电池存档（水银也接受附带 16 字节 RTC 尾部的文件），不支持模拟器即时存档。
ROM 文件名不参与兼容性判断。ROM 仅供读取；修改和导出仅针对存档。

## 操作方式

已解析的宝可梦赠送、赠蛋和定点相遇可关联 NPC 格位、宝可梦资料及收集 HTML。
无可靠格位的来源单列；发放结果与当前可达性仍保留未知，详见
[解析范围与验证](docs/verification/script-pokemon-20261006.md)。
有界 NPC 交换报价可跳转到要求的确切宝可梦和携带道具来源；载入 SAV 后区分
同行／盒子的非蛋候选，不自动生成或交换个体。详见
[原生交换对照及边界](docs/verification/npc-trades-20261006.md)。

编辑器按指纹注册四款游戏的五份精确 ROM，各项验证范围见[能力矩阵](docs/capability-matrix.md)。火箭队的实际性格、第三特性、九类道具
栏位、等级上限、图片和扩展资料表由适配层处理；不再使用临时的只读宝可梦页面。
ROM 资料仍在只读浮窗中浏览。见[覆盖范围、验证与扩展规则](docs/multi-rom-adapters.md)。

- 同行、盒子和编辑页根据 PID 显示未知图腾字形、晃晃斑斑点，普通与闪光配色均从 ROM 读取。详见[外观验证](docs/research/pokemon-appearance.md)。
- 同行和全部 14 个盒子同时展开，可切换紧凑／舒适密度或收起右侧编辑栏。
  搜索只降低不匹配格的亮度，保持真实位置不变。
- 支持种族、昵称、性格、性别、闪光、等级、经验、个体值、努力值、特性、
  技能及 PP、携带道具、来源、蛋、病毒、缎带和华丽度字段。
- 拖拽可移动或交换；按住 Alt 拖拽可复制。也提供“移动到／复制到”按钮。
  按住 Ctrl、Command 或 Shift 点选多个个体，可以批量应用相同字段修改。
- 修改栏位支持输入 当前 ROM 的名称或编号搜索；普通编辑的
  相遇地点按本体及进化前形态筛选，并提供独立的孵蛋来源。规则与验证见
  [搜索和来源说明](docs/research/search-and-origins.md)。
- ROM 资料在可移动的非模态浮窗展示，包含宝可梦、技能来源、道具、特性、地图、
  相遇位置和训练家队伍。训练家与地图可按战斗脚本关联双向跳转，并保留证据
  偏移及条件待核实提示。将相遇条目拖入空格，会先生成草稿，再创建和编辑。
- 进化树支持进化前后、旁支及形态家族反复点击跳转，战斗形态与未确认的名称关联
  分开展示。六围纵排，左列为神百最新收录世代的官方参照，右列为 ROM 数值，底部
  显示总和；自定义或无法唯一对应的种类可手选参照。这个单独署名的小型数值表
  是明确的外部参照，ROM 名称、进化、图片等仍实时读取。见
  [数据来源审查与进化树说明](docs/research/runtime-data-and-evolution-tree.md)。
- 支持玩家信息、金钱、代币、背包、盒子名称及图鉴标记；可查看前后差异、
  撤销与重做。导出前校验，覆盖已有输出时自动备份，并检测源存档的外部变更。
- “自由编辑”允许突破部分游戏规则，仍保留二进制结构和有效 ID 检查。
  例如选择斗笠菇、打开自由编辑、选择“点到为止”，再应用与导出。
  未找到学习来源只表示资料待核实，不直接判为非法。
- 界面中英文即时切换；ROM 自带名称和存档文字不会被翻译或改写。

程序不会修改 ROM。宝可梦的个体值、努力值和特性选择保存在 SAV 中；
种族值是 ROM 的全局数据，不能通过修改单只宝可梦的 SAV 改变。

## 开发与构建

安装稳定版 Rust、Node.js 22+ 及 [Tauri 平台依赖](https://v2.tauri.app/start/prerequisites/)。

```sh
npm ci
npm run desktop
npm run desktop:build
```

测试命令和真实 ROM 回归环境变量详见 [English README](README.md#development)。
公开测试使用合成二进制数据；本地 ROM 回归不会上传 ROM。发布包不包含 ROM、
存档、完整精灵图片集或开发 HTTP 服务。

相遇选表的原生代码验证可使用相同的 ROM 环境变量运行
`python3 scripts/verify_encounter_selection.py`（需要 Python Unicorn）。
已核对的代码路径、昼夜条件结论和验证边界见
[相遇表与时间条件](docs/research/encounter-time-selection.md)。

资料页切换的浏览器回归可先启动 `npm run dev`，再运行
`python3 scripts/test_reference_navigation.py`。需要 Playwright 和 Chrome，
使用合成接口数据，无需 ROM、存档或开发桥接服务。

静态地图的调色板规则及原生 ROM 验证方法见
[地图调色板](docs/research/map-palettes.md)。

宝可梦编辑栏在切换个体时保留当前标签，顶部标签和底部操作区固定，仅中间
内容滚动。启动 Vite 后运行 `python3 scripts/test_editor_navigation.py` 可验证
标签保留、草稿隔离及桌面／最小窗口／手机尺寸下的滚动行为；使用合成数据，
需要 Playwright 和 Chrome。

## 三层结构

- [方法层](skills/gen3-rom-research/SKILL.md)：可独立供 agent 使用，不依赖修改器。
  未知 ROM 研究不要求已登记 MD5。
- [代码层](docs/ARCHITECTURE.md)：统一事务和数据模型；地址、表长、文本分段等
  放入版本配置。格式或引擎变化需要新增解析器／规则，不能只改偏移。
- 应用层：桌面与 CLI 使用同一个 Rust 核心；界面仅维护草稿、展示和用户意图。

代码采用 MIT 许可；格式研究来源见 [第三方说明](THIRD_PARTY_NOTICES.md)。

[解析范围与限制](docs/research/map-events.md)说明了静态位置和未知脚本的处理。

发布记录见 [更新日志](CHANGELOG.md)，从首次公开发布版 0.1.5 起记录。119 号道路钓点依当前存档计算，可在地图图层查看或从宝可梦资料页跳转。

## 查询与收集规划

ROM 资料浮窗支持宝可梦、道具和招式的来源跳转、地图格位定位、连接地图及
外部入口链。打开 SAV 后，在「收集规划」选择图鉴捕获记录或现有个体，可按
永久进化家族合并，按区域查看建议并导出独立 HTML。领取状态不依据背包有无
道具判断；无法确定的奖励需单独勾选。水银目前仅开放按现有个体规划。

缺失宝可梦可展开按永久进化边生成的准备链：优先使用现有非蛋前代，或列出有
地图引用的前代来源，逐步查看进化条件，并跳转所需道具、招式、起点地图及入口。
独立 HTML 包含相同说明。图鉴历史记录不代表当前有可用亲本，不能反转进化边
推断孵蛋；准备链也不证明当前已满足进化资格，分支可能需要额外个体。

脚本条件、动态可达性及特殊获取来源仍有待验证内容；路线是建议，不保证全局
最短。此流程不修改存档，也不自动生成宝可梦、点亮图鉴或修改剧情标记。

水银训练家资料会在隔离内存中执行当前 ROM 的普通配队构造器，显示指定种子下
的生成值；剧情情景状态清零，不涵盖脚本换队、特殊设施和实际入战全部设置。
水银 1.2 的获取查询、收集建议和 HTML 读取 SAV 中的原生虚拟时钟快照，展示日期、
星期、速度及强制夜晚条件；可切换模拟小时或全部时段。硬件 RTC 模式仍不能确定，
不会代入设备时间。只读命令行：`gen3 game-clock ROM [SAVE]`。
详见[时钟验证](docs/verification/mercury-clock-20261005.md)和[验证与当前缺口](docs/verification/query-collection-20261005.md)。

五份 ROM 的已验证持久化事件范围支持隐藏道具及符合原生协议的普通道具球领取
叠加；复杂拾取／NPC 奖励继续保留未验证边界。水银按 ROM 区域列表
实时计算领取标记，地图与收集 HTML 会提示脚下探测器取物。普通 NPC 领奖和完整
任务／刷新机制仍有缺口，见[事件验证](docs/verification/event-state-20261005.md)和
[普通道具球验证](docs/verification/pickup-receipts-20261005.md)。
NPC 奖励新增有界领取证明：核对未领取条件、原生发放成功／失败结果，以及仅成功后
写入的标记。证据与 NPC 消失标记分开；来源可跳转地图，已领取奖励从收集建议排除，
ROM 资料仍显示全部事件。未通过证明的奖励保持未知，查询、规划和中英文 HTML
都有说明。见 [NPC 领取验证及边界](docs/verification/npc-receipts-20261006.md)。

水银 1.2 使用本作扩展背包及原生地点名表。地图中已验证的原生静态布局错乱、
无法确定的图层行为会显示提示；解析出地图记录不代表已证明正常入口或可达性。
验证范围见[水银显示与背包](docs/verification/mercury-display-storage-20261005.md)。

已解析教招报价可从招式查询跳转 NPC 格位、外部入口并返回。漆黑 BW／DP 使用修正后的原生教招表；费用、次数限制和特殊资格继续保留未知，见[教招验证及边界](docs/verification/tutor-sources-20261006.md)。

已解析的道具／金钱检查显示所需道具与持有量，并贯通来源、地图、收集建议和独立
HTML。金钱检查不代表费用或已支付；设施临时背包及脚本改变资源后的判断保留未知。
见[原生条件规则和验证](docs/verification/resource-conditions-20261006.md)。

野生携带道具查询可沿宝可梦跳转到真实相遇地图，保留槽位和时段。概率执行当前
ROM 的普通单只野生携带例程；无存档展示无修正模拟基准，有存档另显示同行首位
情景。携带概率以已遇到该宝可梦为条件，与相遇槽位概率分开；无引用记录不代表
必然可获取。见[原生验证与边界](docs/verification/wild-held-20261006.md)。

宝可梦获取查询新增只读原生寄养预览：选择存档亲本或明确的模拟亲本，跳转情景后代、
已定位领蛋 NPC 与地图。另按普通背包投影或明确的道具情景，执行本 ROM 的普通
产蛋检查、展示情景概率，并跳转加成道具的获取途径。它不预测下一颗真实蛋；西班牙火箭队／水银的
服务位置及完整孵蛋覆盖仍待验证。见[原生寄养证据](docs/verification/breeding-20261006.md)。
产蛋情景的假设与完整随机抽值对照见[独立验证记录](docs/verification/breeding-production-20261006.md)。

加载 SAV 后，还可查看普通寄养的保存快照：实际寄养亲本、原生待领蛋标记和距离
下一次普通产蛋检查的步数；可直接选用原始寄养记录进行只读情景预览。快照不是
模拟器实时状态，检查步数也不是下一颗蛋的保证。水银的额外自定义服务记录尚未
解析。见[寄养保存状态证据](docs/verification/daycare-state-20261006.md)。

收集准备链还会用现有同行／盒子亲本的原始记录与当前携带道具，抽样运行本作普通
后代选择流程，关联领蛋服务、孵化和后续进化；可一键调用完整原生领蛋例程复核，
独立 HTML 同步列出亲本位置。搜索有边界，不是全部后代目录，已寄养个体暂未纳入
此自动配对搜索；没有建议不代表无法孵蛋。见[收集孵蛋证据](docs/verification/breeding-planning-20261006.md)。

前置条件可展开「追查前置线索」，查看可能改变它的地图脚本、当前 ROM 的文字
上下文与其他条件，并跳转格位、入口和返回。独立收集 HTML 附带有界、可跳转的
线索附录，与本次导出的 ROM／SAV 快照一致。这仍是部分线索，不是完整任务树或
当前可达／完成证明。见[验证范围与边界](docs/verification/event-dependencies-20261006.md)。

只读 ROM 资料新增“事件线索”：搜索当前 ROM 的对话上下文／地图引用，查看条件并
追查前置线索，再跳转格位和外部入口。保存标记一致不代表任务已完成或当前可达；
整体仍为部分解析，详见[事件线索验证](docs/verification/event-clues-20261006.md)。

训练家资料可查看已核实的战斗记录引用、脚本条件及 NPC／地图格位，跳转事件上下文
与外部入口。再战基础记录和准备指令单独说明；引用不代表当前可对战或最终配队。
见[原生参数边界与限制](docs/verification/trainer-locations-20261006.md)。

ROM 资料的“游戏时间”页区分水银虚拟时钟与硬件 RTC 情景。其他已注册版本展示 SAV 偏移／检查点，并按当前 ROM 原生例程计算手动输入；当前 RTC、未验证的星期和刷新规则仍为未知。详见[验证边界](docs/verification/hardware-clock-20261006.md)。

ROM 资料的“培育资料”页提供已验证努力值道具的获取跳转，以及同行／盒子／模拟个体的原生效果前后比较；自定义机制、菜单资格、消耗仍为部分验证。见[验证边界](docs/verification/training-items-20261006.md)。只读 CLI：`gen3 training-items ROM`、`gen3 training-preview ROM REQUEST.json [SAVE]`。

培育资料也会实时读取西班牙火箭队的薄荷目标，预览存档／模拟个体的实际性格与能力。在已验证的改变情景中，现有性格覆盖值修改与原生持久化效果一致，保留 PID、身份和历史；菜单、消耗及其他 ROM 的薄荷服务仍未确认。见[证据与边界](docs/verification/training-natures-20261006.md)。
